# Dodle Web v1.2.0 Changelog

## Dodle Spider

- Expanded the command-line HTTP client with style request options
- Added JSON, raw, binary, multipart form, file, and stdin request bodies
- Added arbitrary HTTP methods, uploads, redirects, ranges, and resumed downloads
- Added response header output, header dumps, failure handling, and write-out summaries
- Added compression, user-agent, referer, client certificate, and CA bundle options
- Improved silent mode, help output, timeout handling, and non-HTTP response handling
- Bumped the spider package and CLI version to `1.2.0`
