# Dodle Web v1.1.0 Changelog

## Dodle Spider

- Added the `web/spider/dodle.py` command-line client for HTTP and HTTPS requests
- Added native support for requests, headers, request data, authentication, cookies, redirects, proxies, TLS, timeouts, retries, downloads, response headers, and verbose output
- Added packaging metadata and the `dodle-spider` command
- Documented Spider usage in the main web README
